# ระบบตรวจสินค้าใหม่ (RA)

เว็บสำหรับให้ฝ่ายจัดซื้อส่งข้อมูลสินค้าใหม่ให้ RA ตรวจ แล้ว RA กด Approve หรือ Reject

## ขั้นตอนการทำงาน

1. **ฝ่ายจัดซื้อ** กรอกข้อมูลให้ครบ 4 ส่วน
   - ชื่อสินค้า
   - Ingredient: แนบไฟล์ (PDF / รูปภาพ / .txt) และกรอก % ของวัตถุดิบ ต้องรวมได้ **100% พอดี**
   - Nutrition: แนบไฟล์
   - Process Flow: แนบไฟล์

   ถ้าขาดส่วนใดส่วนหนึ่ง หรือ Ingredient รวมไม่ถึง 100% ปุ่ม "ส่งให้ RA ตรวจ" จะกดไม่ได้
2. **RA** เห็น Ingredient ก่อน ติ๊กตรวจทีละรายการ แล้วกด
   - **Approve**: กดได้เมื่อข้อมูลครบและติ๊กตรวจ Ingredient ครบทุกแถวแล้ว
   - **Reject**: ต้องใส่เหตุผล งานจะถูกส่งกลับให้จัดซื้อแก้ไขแล้วส่งใหม่
3. ไฟล์ทั้งหมดเก็บใน Google Drive โฟลเดอร์ **RA ตรวจสินค้าใหม่** แยกเป็นโฟลเดอร์ย่อยตามชื่อสินค้า

## ข้อควรรู้ก่อนเอาขึ้นเซิร์ฟเวอร์

ตอนนี้การเก็บข้อมูลร่วมกันระหว่างจัดซื้อกับ RA และการอัปโหลดไฟล์ลง Google Drive ทำงานผ่านระบบของ Claude ซึ่งใช้ได้เฉพาะตอนเปิดหน้าเว็บใน claude.ai

ถ้าเปิดไฟล์นี้จากเซิร์ฟเวอร์อื่น (เช่น GitHub Pages หรือเว็บโฮสติ้งของบริษัท) หน้าจอ การเช็คความครบ และปุ่มต่าง ๆ ยังใช้ได้ แต่ข้อมูลจะอยู่แค่ในเบราว์เซอร์ที่เปิดอยู่ และอัปโหลดไฟล์ลง Drive ไม่ได้ ถ้าจะใช้งานจริงบนเซิร์ฟเวอร์ของบริษัท ต้องเพิ่มระบบหลังบ้าน (backend) เช่น Google Apps Script มาเก็บข้อมูลและส่งไฟล์เข้า Drive แทน
